# Open Spec

Repositorio dedicado al estudio de Specification-Driven Development (SDD) y OpenSpec.

Este repositorio contiene:

- Conceptos consolidados del curso de Álvaro Moya.
- Investigaciones sobre OpenSpec.
- Buenas prácticas.
- Patrones de uso.
- Experimentos y documentación de apoyo.

No contiene código del proyecto Smart Parking Platform, que se desarrolla en el repositorio `sdd-lab`.
