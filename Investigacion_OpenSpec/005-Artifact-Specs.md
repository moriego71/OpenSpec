# 005 - Artifact: Specs

## Objetivo
Definir **qué** debe hacer el sistema.

## Estructura
Una especificación por Capability.

```text
specs/
    <capability>/
        spec.md
```

## Contenido
- Requirements
- Scenarios

## Reglas
- Cada Requirement debe tener al menos un Scenario.
- Los escenarios utilizan formato WHEN / THEN.
- Los escenarios representan futuros casos de prueba.

## Dependencias
- Proposal

## Desbloquea
- Tasks
