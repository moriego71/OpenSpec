# 007 - Comandos CLI

## Inicialización
```bash
openspec init
```

## Crear Change
```bash
openspec new change <nombre>
```

## Estado
```bash
openspec status
```

## Mostrar
```bash
openspec show
```

## Validar
```bash
openspec validate
```

## Dashboard
```bash
openspec view
```

## Instrucciones para IA
```bash
openspec instructions <artifact>
```
